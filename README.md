# Task Manager Web Application

A modern, responsive task manager web application built with HTML, CSS, and JavaScript. Allows users to add, delete, and mark tasks as completed with persistent storage.

## Features

- Add new tasks
- Mark tasks as completed/incomplete
- Delete tasks
- Persistent storage using localStorage
- Modern, responsive design
- Semantic HTML for accessibility
- Keyboard navigation support

## Technologies Used

- HTML5 (Semantic markup)
- CSS3 (Modern styling with CSS variables)
- JavaScript (ES6+ for functionality)

## Prerequisites

- A modern web browser
- (Optional) A local server for development

## Quick Start

1. Open the project folder.
2. Start a local server (recommended):
3. Display Textual content related to page.

```bash
python3 -m http.server 8000
```

3. Open `http://localhost:8000` in your browser.

Alternatively, open `index.html` directly in your browser.

## File Structure

- `index.html` - Main HTML file with semantic structure
- `styles.css` - CSS styles for modern, responsive design
- `app.js` - JavaScript for task management functionality
- `README.md` - This file

## Usage

- Enter a task in the input field and press Enter or click "Add Task"
- Check the checkbox to mark a task as completed
- Click "Delete" to remove a task
- Tasks are automatically saved to localStorage

## Accessibility

- Screen reader friendly with proper ARIA labels
- Keyboard navigation support
- Semantic HTML structure
- High contrast colors

## Responsive Design

The application is fully responsive and works on desktop, tablet, and mobile devices.
